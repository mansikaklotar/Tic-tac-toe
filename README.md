# Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

This project was created for learning purposes and to improve JavaScript skills, especially DOM manipulation, event handling, game logic, and dynamic UI updates.

## Features

* Two-player interactive gameplay
* Dynamic winner detection
* Reset and New Game functionality
* Responsive and clean UI
* Interactive game board
* Modern styling and hover effects
* Real-time game result messages

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How to Play

1. The game is played between two players: X and O.
2. Players take turns clicking on empty boxes.
3. The first player to align three marks horizontally, vertically, or diagonally wins the game.
4. If all boxes are filled and no player wins, the game ends in a draw.
5. Use the Reset or New Game button to play again.
